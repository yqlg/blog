# 关于

## 你好

我是 Liny，一名喜欢把东西做出来的开发者。

白天写代码，晚上读一点书。这个博客用来存放那些值得留下来的东西：技术上的笔记和踩坑，生活里的观察和心情。它们不一定正确，但都真实发生过。

## 这个博客

它没有数据库，没有服务器，也没有后台管理系统。整站是一堆 Markdown 文件，提交到 GitHub，由 GitHub Actions 自动构建成静态页面，再发布到 GitHub Pages。

| 环节 | 方案 | 花费 |
| --- | --- | --- |
| 写作 | Markdown + VitePress | ¥0 |
| 版本管理 | Git / GitHub 仓库 | ¥0 |
| 构建部署 | GitHub Actions | ¥0（公开仓库不限额度） |
| 托管 | GitHub Pages | ¥0 |
| 备用镜像 | Cloudflare Pages | ¥0 |
| 域名 | `yqlg.github.io/blog` 或自购域名 | ¥0 起 |

具体的搭建方式和写作流程写在仓库的 README 里，想抄作业可以直接 fork。
