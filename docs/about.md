## 这个博客

它没有数据库，没有服务器，也没有后台管理系统。整站是一堆 Markdown 文件，提交到 GitHub，由 GitHub Actions 自动构建成静态页面，再发布到 GitHub Pages。

| 环节 | 方案 | 花费 |
| --- | --- | --- |
| 写作 | Markdown + VitePress | ¥0 |
| 版本管理 | Git / GitHub 仓库 | ¥0 |
| 构建部署 | GitHub Actions | ¥0（公开仓库不限额度） |
| 托管 | GitHub Pages | ¥0 |
| 评论 | giscus（GitHub Discussions） | ¥0 |
| 统计 | Cloudflare Web Analytics | ¥0 |
| 域名 | `yqlg.github.io/blog`（暂用免费二级域名） | ¥0 |

没有广告，也不接入任何追踪脚本；统计用的是 Cloudflare 的无 Cookie 方案，只关心「哪篇文章被读过」，不关心「你是谁」。
